# CA7 黑历史档案馆 — The Aveiro Files

> 一部关于争议的全记录。系统收录 C 罗职业生涯 56 起争议事件，横跨人设、场内暴力、场外失态、俱乐部与法律、国家队五大类别。

**线上地址**：<https://axtrivc.github.io/black-camel/>

## 这是什么

一个纯静态的球迷文化创作网站，以"机密档案"的形式整理 C 罗（本名 Cristiano Ronaldo dos Santos Aveiro）职业生涯中的公开争议事件。所有内容均基于公开新闻报道整理，不代表任何官方立场。

## 技术栈

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建步骤
- 数据与视图分离：`data.js` / `extra-data.js` 存数据，`app.js` 负责渲染与交互
- 部署在 GitHub Pages

## 项目结构

```
index.html              # 单页入口
favicon.jpg
assets/
  css/style.css         # 样式（含三套主题）
  js/
    data.js             # 56 起事件 + 分类配置 + 时间线 + 语录
    extra-data.js       # 创意模块数据（梅罗PK / 检测仪 / 烧钱榜 / 表情生成器）
    app.js              # 渲染与交互逻辑
  images/               # 事件图 / 嬷照 / 绰号图 / 场景图
```

## 三套主题

顶部导航可切换：

- **小小罗**（默认）：曼联红黄配色
- **沙漠骆驼**：利雅得胜利黄蓝深底
- **菌鞭罗**：皇马纯白底浅色主题

## 功能模块

- **档案库**：56 起争议事件卡片，支持分类筛选、严重程度筛选、关键词搜索、模态框翻页浏览
- **梅罗 PK 大战**：8 个维度对比 C 罗与梅西（红牌、世界杯、点球、金球等）
- **点球含金量检测仪**：9 项"注水"指标 + 综合含金量仪表盘
- **CA7 表情生成器**：选图 + 填字 + 下载，一键造梗
- **罪恶账本烧钱榜**：争议金额流水
- **绰号进化史**：9 个绰号的来历与争议
- **数据可视化**：红牌分布、争议分类占比、私生活数据
