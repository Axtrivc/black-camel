## 双语系统实施计划（最终版）

**核心机制**：默认英文 `en`（localStorage 记忆）；`setLanguage()` 派发 `CustomEvent('ca7:lang-change')`；各闭包模块自治监听重渲染。`applyStaticI18n()` 用 innerHTML + 安全白名单（仅允许 `<strong><em><br><span class>`）防 XSS。有状态模块（测试/真假）切语言时仅更新文本不重置进度。

**8 步执行**：
1. CSS `.lang-switcher`/`.lang-btn` + galactico + 移动端
2. app.js 顶部 i18n 机制（currentLang/tt/setLanguage/applyStaticI18n/updateLangBtn/按钮绑定/初始化）
3. data.js i18nDict(en/zh ~150key) + catConfig.labelEn
4. index.html 语言按钮 + data-i18n 全站标记 + 跑马灯/BREAKING 改 JS 渲染 + 绰号卡片移入数据
5. app.js 渲染点改 tt() + 各模块加 lang-change 监听 + 一次性块封装
6. data.js events 61条(titleEn/summaryEn/dateEn/locationEn) + timeline 24条 + quotes ~50条
7. extra-data.js pkData/penaltyData/moneyLedger/memePresets/quizData/truthOrFake/casinoBets 全补 _En
8. app.js 硬编码补 En（PRESET_DANMU/PROMPTS/defs/TITLES/verdict/sevLabel/career/散落文案）

**范围边界**：events.detail 长文留第二阶段；不引第三方库；不译 localStorage 已存数据/图片内嵌文字/SEO og:locale。
