# 第七版补丁 · 图片重新对版（2026-07-03）

## 问题
用户反馈"很多图片与相关事件货不对版"。审计发现根本症结：
1. **文件名严重误导**：workbuddy 从维基下载的图文件名与真实内容不符。例如 `mu_2009.jpg`（看似曼联2009）实际是皇马白球衣；`rm_2013/rm_2017/juv_2018.jpg`（看似皇马/尤文）实际全是葡萄牙国家队图。
2. **通用图滥用**：id:30-63 共 34 个事件原本套用 gallery 通用图，且大量重复（rm_2017 被用5次、juv_2018 被用5次），导致 2018尤文图被套在 2022转会、摩根采访等完全不相关事件上。
3. ev-01~29 早期配图也有错配（如 ev-01 葡队图配给了逃税案这个皇马俱乐部事件）。

## 解决
用 vision 工具逐张识别全部 45 张图（ev-01~29 + gallery 16）的**真实球队/年份/场景**，建立图片档案。然后按「球队匹配 > 年份接近 > 颁奖事件用颁奖图 > 避免单图过度复用」原则重新分配全部 63 个事件。

核心改善（抽查全部对版）：
- 俱乐部事件 → 对应俱乐部图（皇马事件用皇马白、曼联事件用曼联红）

- 颁奖/金球事件 → 皇马金球颁奖图（ballon/ev-17/ev-18/ev-25）

## 局限（已是最优解）
